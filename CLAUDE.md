# Bookshelf

Technical books and articles the owner has read. A PDF is committed only once it has been read.

- File names: `<author-full-name>-<title>-<year>.pdf`, lowercase ASCII, words separated by dashes,
  first author only, e.g. `robert-c-martin-the-clean-coder-2011.pdf`.
- When committing a PDF, add its row to the matching table in `README.md` in the same commit:
  `| [Title](file.pdf) | Author | Year |`.
- Commit and push directly on `main`; no worktrees, branches or PRs.
